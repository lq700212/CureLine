# CureLine（WPF 融合版）

从 VB 老项目（`PLC_ReadData` 单机固化收料 + `PLC_ReadDataA` 八机通用网关）
融合重构的 .NET 8 解决方案，含两个可独立部署的 WPF 程序：

* `src/CimGateway` — 主程序（程序②，CIM 整线过账网关；原名 PlcMesBridge，V0.0.21 改名）：MES 多机网关（八机 Modbus TCP 统一底座；
  Phase 2 演化为程序② CIM 整线过账，单机模式已删）
* `src/CureStation` — **程序①固化程控**：IO 耦合器（Modbus TCP）30 仓位程控
  （双架 60）——点表"点点鼠标"配置 + 主窗仓位网格（V0.0.25 方案 D 版式 +
  Light/Dark 双主题 `[setting] Theme` 切换 + 日志悬浮窗）+ 仓位状态机
  （到位计时→放行→三色灯）+ 工艺策略窗（时长三级覆盖/光栅门控）+
  单线过账 + 工单/权限页 + 配置自愈

详见 `AGENTS.md`（开工必读）、`docs/重构设计_20261028.md`（两程序拆分设计）
与 `CHANGELOG.md`。

## 快速开始

```powershell
# 1. 拉代码（含子模块）
git clone https://github.com/lq700212/CureLine.git
cd CureLine
git submodule update --init

# 2. 编译子模块（net472，需 VS MSBuild）
& "D:\Program Files\Microsoft Visual Studio\18\Enterprise\MSBuild\Current\Bin\MSBuild.exe" `
  "extern/kaleidoscope/Kaleidoscope/Kaleidoscope.csproj" `
  /p:Configuration=Debug /p:Platform=AnyCPU /t:Build /nologo /v:m

# 3. 全量构建 + 测试
dotnet build CureLine.slnx --nologo
dotnet test tests/CureLine.Tests/CureLine.Tests.csproj --nologo

# 4. 模拟联调（无真机；两程序共用同名键 config.ini [setting] Simulate=1）：
#    - CimGateway：复制 config.sample.ini 到其 bin 的 config/config.ini，
#      设 Simulate=1（多机网关直起即模拟 8 机台跑全流程）
#    - CureStation：程序①自己的 bin 下 config/config.ini 设 Simulate=1，
#      启动即 Mock 总线按仓位流转演示（30 卡片 + 周期演示掉线重连）
```

## 架构（MVVM）

- View（`src/CimGateway/*.xaml` 纯绑定）← ViewModel（`ViewModels/`：
  状态 + 命令，`ViewModelBase` 管通知与跨线程封送）→ Model/Core
  （业务，可测）+ `IDialogService`（VM 开窗/提示唯一出口）。
- xaml.cs 只做三件事：设 DataContext、PasswordBox 密码转交（不可绑定）、
  转发关窗；VM 禁止碰 Window/MessageBox/Dispatcher；后台节拍经
  `UiInvoke` 回 UI 线程。
- VM 基建（`ViewModelBase`/`RelayCommand`）已下沉
  `src/CureLine.Core/ViewModels/`（namespace 不变，两程序共用）；
  `IDialogService` 各程序自建（窗集合是私有资产，不下沉）。

## 程序① CureStation（固化程控）

- **主窗（V0.0.25 方案 D 版式）**：上下两条信息带夹网格——顶部运行条
  （连接状态/当前策略/过账状态/重连 + 【日志】【深色】入口按钮）与统计条
  （空闲/待门控/计时/放行/异常五态计数 + ⚡剩余最短库位），底部工单带
  （R/L 双工位纪要 + 进度条）。仓位卡每台固化架 **三排（上中下三层）× 一排
  10 站**，卡片主标题为客户库位编码（Date Matrix：A01~J12，换算收在 Core
  `SlotLocationCode`，后续扫码绑定同源复用）；卡片 5px 状态头带 + 状态
  浸染六态（空闲/待门控/计时中/放行/异常/未配置），计时中显示剩余分钟
  大数字 + 4px 进度条，异常卡呼吸脉冲；旧版托盘/光栅状态点与架层角标
  已随方案 D 精简（状态统一由六态色表达）；默认最大化启动，网格随窗口
  拉伸均分（不同分辨率自适应，MinWidth=1200 兜底）；500ms 拉快照刷新。
- **双主题（V0.0.25）**：主窗与日志悬浮窗全套配色收在语义键（`Brush.*`
  同名异值两字典）：Light（浅色渐变浸染，缺省）与 Dark（深空玻璃舱）；
  config.ini `[setting] Theme=Light|Dark`（非法值回 Light），顶栏【深色/
  浅色】按钮切换即写回盘上；其余功能配置弹窗维持 Fresh 浅色（固定键
  不随主题换肤），弹窗随主题属后续待办。
- **日志悬浮窗（V0.0.25）**：顶栏【日志】按钮（L1+ 门禁）弹非模态悬浮窗
  （右下角贴主窗右下沿、Owner=主窗，单实例防重复开）：左栏操作日志流
  （`LocalLogService` 事件驱动入队、100ms 批量上屏，最新在上封顶 200 条），
  右栏系统状态卡（打开一刻定格快照，含当日日志目录路径）；关窗退订事件，
  再开不重复订阅。
- **双固化架（V0.0.20）**：一台工控机可接两台架（60 卡）——主窗按架分组
  上下堆叠，每组"N号固化架"标题条 + 组内 10×3；**单架时标题条自动隐藏，
  界面与单机版完全一致**。接入方式全在点表配置窗点点鼠标：添加第二台 IO
  耦合器（自己的 IP）→ 缺省模板"起始架号"填 11（生成架 11~20）→ 保存。
  两台架撞架号会被跨设备查重拦下（架号必须全局唯一）。库位编码每台架各自
  一套 A01~J12（标签贴在每台架自己的仓位上）。双架过账分工位：过账配置窗
  "架号段:工位"映射（如 `11-20:L`），L 工位还可配专用机台号（缺省同主值）。
- **登录与四级权限（P3.2）**：顶栏"登录"进四级操作员（L1 操作员/L2 班长/
  L3 工程师/L4 管理员，对照参考 HMI）；主窗功能入口按级别门禁——工单 L1+、
  工艺策略 L3+、IO 测试 L3+、点表/权限管理 L4+，未登录一律拦下。账号存 operators 表
  （PBKDF2 哈希），初始 admin/123456 上线必改；防锁死：最后一个 L4 不可删/降。
  **登录窗功能对齐参考 mFormLogin（V0.0.20 补丁）**：用户名下拉列在册账号
  （可点选可手输）+ 记住密码（按账号各记各的，DPAPI 密文存 config.ini 无
  明文，换账号自动跟出该账号记住的密码）+ 登录窗内置**修改密码面板**
  （改用户名框里账号的密码：验原密码 → 新密码≥6 位且不得与旧相同 → 两次
  一致，写盘即生效，成功同步记忆）；键盘链：回车逐框跳转、Esc 逐层返回。
- **工单信息窗（P3.2）**：R/L 双工位（途程单号/预设数量/已生产数量 + 计数
  清零）+ 员工工号 + 物料条码 + 制程代码×2 + 物料上传使能；窗内编辑区再按
  级别细分禁用（途程/数量 L2+、制程 L3+）；存 `config/workorder.json`
  （字段名与 MES 16 字段对齐，过账直接映射）。**物料上传（P3.2 后半）**：
  批次物料区"上传 R/L 物料"两按钮——先保存工单再后台提交 API0032（刚录
  条码即时生效），结果看主窗顶栏过账状态。
- **单线过账（P3.2 后半，复刻老项目"装载/卸载"命令字）**：托盘到位=进站
  （API0030 I），托盘离开=固化时间（API0027）+出站（API0030 O），出站被
  MES 接受（STATUS=1）→ 对应工位"已生产数量"自动 +1。**全配置化**：
  总开关/工位/固化时间单位/进站时机/中途取件口径/静态参数/三接口 URL 全在
  **过账配置窗（L4）**改，保存即生效（热更新不重启）；总开关关或 URL 空
  不发任何请求；失败只记日志与顶栏状态（不弹窗不重传，防重复过账）。
- **仓位状态机（程控核心）**：托盘到位 →（门控开则等光栅让空）→ 黄灯计时 →
  到点绿灯放行 → 托盘离开灭灯回空闲；任何时刻托盘离开都回空闲（计时中取件
  记日志）。灯写/计时全在后台线程，断连恢复自动对齐重计，灯写失败下轮补写。
  **断电续算可配置**：策略勾"断电续算"后进行中仓位随状态变化落盘
  `config/curingstate.json`，重启按记录续算（断电时间计入固化时长）；缺省关
  =断电重计（宁可重计也不放行没固化够的货）。
- **工艺策略窗（参考 AgingTestSystem 配方管理模式 + 预置库）**：策略库
  增删选 + 编辑（策略名/全局时长/光栅门控/每层覆盖/每仓位覆盖行表）+
  **激活并生效**（保存+启用选中策略）+ **仅保存**（先校验后落盘，错弹框
  不写文件）。时长三级覆盖：仓位 > 层 > 全局，缺值自动回退，三种粒度可
  混用；光栅门控可开关（开=左右光栅都灭才开计时）。**预置策略库**：
  出厂自带 5 个预置样例（标准 120/快速 60/深度 240/分层固化/特殊仓位
  示例——顺带演示每层与每仓位覆盖怎么配），选中预置可查看修改参数，但
  保存请点**【套用为自定义策略】**（修改落到"自定义"并自动激活）——预置
  本身不能激活/删除，保证出厂推荐可回溯；**激活只认自定义策略**，开窗
  默认选中"自定义"。**仓位时长可视化画布**（窗口底部）：每仓位一格按
  解析时长四档着色（绿<60/黄/橙/红≥180 分钟）+ 图例，编辑参数实时反映；
  支持拖动平移、滚轮缩放、双击复位。
- **IO 通讯测试窗（顶栏"IO测试"，L3+；现场接线验证）**：按点表铺仓位卡
  网格（与主窗同布局）——DI 只读状态灯（500ms 自动刷新）+ DO 点击灯钮
  （点击切换 ON/OFF，写入失败灯弹回真实读数）；**一键遍历**=500ms/路
  跑马灯逐路点亮快速验接线（再点停止并全部关闭）+ 全部关闭复位；共享
  主窗总线连接（不另建 TCP），操作全程日志。**换项目零代码**：通道清单
  完全来自点表配置，改点表即适配新线体。
- **点表配置窗（"点点鼠标"核心，现场不改代码）**：设备增删（IP/端口）+
  **一键缺省模板**（按起始架号×架数×层数生成全套绑定，双架第二台填 11）+
  **设备高级参数**（端口/从站号/DI·DO 起始地址/块跨度/每块点数/超时/轮询
  周期/输入·输出取反——支持 0x 十六进制与十进制）+ 绑定行增删改（块/位/
  方向/角色/架/层/功能名）+ **测试连接**（三态文字诊断：连不上/连上读不通/
  OK）+ **保存**（先全量校验再落盘：物理点唯一 + 语义键全局唯一两道闸
  （跨设备也查重），错弹框不写文件）。
- **自愈**：`config/pointtable.json` 缺失/损坏 → 自动按 Audi cover module
  IO 表生成缺省模板（10 架 3 层）并落盘；`config/curingpolicy.json` 缺失/损坏
  → 缺省策略库（"标准固化"120 分钟）落盘，开箱即看。
- **点表布局（缺省，与电气 IO 表对应）**：块 K=架（起始架号+K−1），块 K 的
  DI=0x1000+(K−1)×0x20、DO=DI+0x10；块内每 4 位一组=1 层——输入组
  bit0=左光栅/bit1=右光栅/bit2=托盘，输出组 bit0=红/bit1=黄/bit2=绿；
  起始地址/步进/取反三键均可配（点表窗"设备高级参数"），代码零改。

## 界面设置

- 菜单栏"登录"按钮 → 登录窗（两档账号：admin 普通管理，
  dev 最高权限；"记住密码"按账号各记各的 DPAPI 密文，用户名框改谁就跟出谁的）。
  已登录再点可退出或切换账号；设置子项未登录会先提示登录。
  账号存数据库 users 表（PBKDF2 哈希，无明文），上线前必须改掉初始密码。
- 菜单栏"设置"下拉：admin 见"修改密码" + "创建桌面快捷方式"，
  dev 另见"网关设置"。"修改密码"自己改自己（dev 可下拉代改他人），
  新密码≥6 位。
  "网关设置" → 网关配置窗（两页：机台连接 / 接口地址）：IP/端口/接口地址
  全界面改，"测试连接"拿表单值直测（不用先保存），"保存并重启"先校验
  格式、错当场拦，通过后自动重启生效。
  去现场只点鼠标，不改代码不改 ini。
  W68 联调预备（V0.0.22 起全配置化）：接口页含 6 接口的 URL/触发字/数据/
  MSG/DATA/状态/完成 7 项 + 数据长度 + **分段偏移**（API0030/0031 返回 DATA
  三段拆写 DATA/+30/+60 的偏移，缺省 30,60；终版拆段规则不同改这里即可）；
  多机页含每台 IP/端口/启用 + **扫描周期ms**（触发轮询间隔，缺省 200，
  保存即热生效无需重连）。字符串字节序（StringByteOrder）等其余键见
  `config.sample.ini` 注释。
- "创建桌面快捷方式"：一键在桌面建 `.lnk`（图标取 exe 内嵌图标，
  已存在不覆盖只提示路径）。exe/任务栏/全部 8 个窗体左上角图标统一为
  `src/CimGateway/Assets/app.ico`，换图标只换该文件重新编译。
- 风格：天蓝色小清新全局样式（`src/CimGateway/Styles/FreshBlue.xaml`）。
