中等工作量

方案对比与建议

方案内容改动范围量级定位
A 现状 8 卡日志流（老 Form1 复刻） — — 通讯网关视角，过账零可视化
B 卡片业务化 S2：6 接口微表 + 最新消息行；S4：机台名中性化 Core 加观测事件 + StationPanel 重排 + 两 VM 中 每台过成情况一眼可见
C ＝B+汇总 S1 整线汇总条 + S3 单机视图增强 + S5 周期口径 主窗筛选条升级 + 单机模板 中 推荐：补齐"整线"语义，与程序①观测面对等
建议：方案 C，分两批落地——第一批 S4 机台名中性化 + S1 汇总条 + S2 卡片业务化 （不等 W68 终版，模拟数据即可成形）；第二批 S3 单机增强 + S5 周期口径 随 P2.2 联调； S6（0028 存图链去留）挂起待 W68 拍板。全程零改协议与回写口径。
说明：① 本稿全部为演示数据，非现场实测；② 配色仅为示意，实施走 Brush.* / Brush.Fresh.* 主题语义键（深浅主题同名异值）；③ 卡片 MinWidth=280、4 列网格与现状一致，最小窗宽 960 不变； ④ 协议红线（触发→组包→POST→回写、STATUS=2/MSG=NG、DATA 拆包无补零、分帧 125/123、失败不重传）零改动。
