# 整线网关 操作员手册

> 适用版本：整线网关（CimGateway）V0.0.22 及以后
> 适用对象：产线操作员 / 值班班（正常无需管理员权限即可完成全部操作）
> 截图说明：截图均为**演示模式**数据；机台编号、报文内容以现场为准。

---

## 1. 这套软件是干什么的

整线网关安装在**产线控制柜的工控机**上，是 8 台设备与 MES 系统
之间的"传话筒"：

1. **设备侧**：设备把生产触发信号送给软件（走以太网）；
2. **MES 侧**：软件把配方/异常/产量按时装进看板，自动上传 MES、
   收 MES 回执再回写设备——设备照常干活，MES 照常记账，中间不用
   人干预。

你在软件里的日常就三件事：**看连接、看日志、处理报警**。

## 2. 打开软件与界面总览

双击桌面快捷方式（或开始菜单里的 **CIM通信网关**），软件自动出
主窗：

![主窗空闲态：8 机台面板+顶栏](images/gw-main.png)

| 区域 | 说明 |
| --- | --- |
| 顶栏菜单 | MES 交互实时日志 / MES 接口调试界面 / 设置▼ / English / 登录 / 当前时间 |
| 连接设备 | 蓝色按钮，一键把全部 8 台设备连上 |
| 视图 | 筛选显示"全部机台"或某一台 |
| 8 张机台面板 | 每台一张卡：设备名 + 状态灯圆点 + 日志区 |

**状态灯圆点**（每张面板右上角）：

- **灰**：未连接（软件刚启动或设备断线）；
- **绿**：连接正常，可在面板里看实时触发日志；
- **红/闪**：连接异常（设备关机/网线掉/网络抖动——软件每 5 秒自动
  重试重连，无需手工干预）。

## 3. 连接设备

点 **连接设备**：

![连接中过渡态](images/gw-main.png)

- 按钮短暂变成"连接中..."——软件正在逐台握手；
- 之后各面板圆点逐台转绿，面板日志区开始滚动"触发/上传/回写"行；
- 中途某台连不上，只影响那一台面板（灰点+日志给原因），
  其它照常。

> **软件启动不会自动连**设备——每次开机后需点一次"连接设备"，
> 这是防止半夜重启一起连上产线造成触发半路停的设计选择。

## 4. 看机台面板与筛选视图

连上后**每张面板**内容：

| 区块 | 说明 |
| --- | --- |
| 面板标题 | 设备名（现场 8 台各有专名，见《交付清单》） |
| 右上圆点 | 连接状态（对应上表） |
| 日志区 | 实时滚动该机的触发/上传/回写行 |

**面板滚动的日志行随触发生成**——没有生产动作时是安静的，
这是"只在动作时刻发消息"的设计，不是软件卡住。

**视图筛选**：连接按钮旁"视图"下拉，可切"全部机台"或只看某一台——
只在排查一台时用，日常看全部。

**MES 交互实时日志窗**：顶栏点它弹独立窗：

![MES 交互实时日志窗（全部机台）](images/gw-log.png)

- 面板里滚的是**摘要行**，日志窗里滚动**完整报文行**（含请求与
  MES 返回原文）——排查时先面板、再日志窗；
- 窗口右下角 **清空当前显示**；显示内容一直向下滚滚时用；
- 支持按机台分栏（配"视图"筛选切到单机台时更聚焦）。

## 5. 报警窗（出现红字怎么办）

上传失败、MES 拒单时软件**自动弹报警窗**：


示例行意思：`上传失败: API0028 返回非 1（STATUS=2, MSG=设备号不存在)`——

- **API0028**：哪个接口（对应什么报什么，看《整线网关 客户技术工艺
手册》接口表）；
- **STATUS=2 / MSG=设备号不存在**：MES 侧拒绝的原因，**报文内容
不对**（现场常见：设备编号在 MES 上没建档）；
- 处理原则：**先抄录报警行**（截图也行）→ 对照手册第 8 节常见问题
→ 解决不了把截图给工程师——不要连点关闭窗口当没有事。

## 6. MES 接口调试界面（日常排障主工具）

顶栏 **MES 接口调试界面**：

![MES 接口调试窗](images/gw-debug.png)

用途：**手动发一条报文试链路**，不用等设备真触发。

操作四步：

1. 接口类型：选中要试的接口（常探的几个见接口表）；
2. 参数框：把当前机台的途程单号/制程代码等填进去（多数时候默认值
   就是最近一次真触发拿到的参数，直接试链路即可）；
3. 点 **手动上传到MES**——下方"发送报文预览"先给你看**实际要发的
   JSON 报文**，MES 返回原文显示在"返回信息"区；
4. 对返回判定：返回码做通过、FAIL/错误原因对照接口表。

调试窗里改的参数只是**本次试验**用的，**保存参数到本地**才落
（下次打开默认带出）——日常不动它也不会影响真触发链路。

> 本窗口是**连接试验版**，不依赖设备连接（单独在机台场景也用得上
> ——写完直接点上传，设备侧无需任何动作）。

## 7. 登录 / 修改密码

顶栏 **登录**：

![登录窗](images/gw-login.png)

- 用户名、密码、记住密码（勾选后下次自动填，密码加密保存）；
- 普通**操作账号**即可登录——登录后才能做"修改密码"。
- 若您是**临时用工程师 DEF 账号**临时查问题，用完**务必点退出**，
  别留给下一班。

顶栏【修改密码】按钮：

![修改密码窗](images/gw-changepwd.png)

- 账号：下拉预填当前登录人；
- 旧密码 / 新密码 / 确认新密码——新密码至少 6 位；
- 修改成功后下次登录用新密码；
- **忘了密码**：由管理员重置（您的账号在他那看得到）。

> 设置菜单里其它项（管理员专属）不属于操作员范围——本手册不展开，
> 需要时看《交付清单》或公司内部手册。

## 8. 常见问题

**Q1：面板圆点是灰的，怎么处理？**
先看设备（开机吗/线通吗/设备侧软件开着吗）——多数是设备没起。
软件侧每 5 秒自动重连，设备恢复后圆点自己转绿。

**Q2：面板里几小时没动静，是不是软件挂了？**
没有生产动作就没有日志——这是设计为静态只在动作时发消息。
看面板圆点：绿色 = 在线待命；或从日志窗核对最后一次报文时间。

**Q3：弹了报警窗，我该做什么？**
**抄录报错行**（截图）→ 对照第 5 节口径 → 处理不了给工程师，
**不要闷头反复手动重试**——重复上传可能造成 MES 侧重复记账。

**Q4：MES 一直没回执/一直失败？**
调试界面点一次"手动上传到MES"，看返回信息——
- 网络通（有返回）：看返回码是什么（STATUS=2/设备号不存在等，
  报给客户 MES 侧对齐设备编号）；
- 无返回（超时）：报给工程师（网络/URL 需要用配置核对）。

**Q5：屏幕上的日期/时间是 24 小时制吗？**
顶栏时钟直接取本机系统时间，**必须与设备主**时间一致——
发现相差超过 1 分钟，先叫网络管理员对时（同步影响 MES 对账）。
