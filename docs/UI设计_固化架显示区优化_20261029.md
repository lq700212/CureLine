## 1. 现状与避免返工的背景

主窗三段：顶栏（状态+按钮）→ 组标题条（双架时显示）→ 30 张仓位卡
（UniformGrid 10 列 × 3 行，最大化时每卡约 180×250px，Stretch 均分）。

当前卡片实现在两处，都是骨架期产物：

| 文件 | 内容 | 备注 |
| --- | --- | --- |
| `src/CureStation/MainWindow.xaml` | `<DataTemplate x:Key="SlotCard">`卡片模板（31-94 行） | 4 行小字：码+层名 / 状态 / 灯点+灯色+托盘 / 光栅 |
| `src/CureStation/ViewModels/MainViewModel.cs` | `RackSlotViewModel`（27-129 行） | 已有 Code/Title/SlotStateText/LampText/TrayText/GrillText/CardState |
| `src/CureLine.Core/Curing/SlotCuringMachine.cs` | `SlotStatus(Phase, TotalMinutes, RemainMinutes)`（49 行） | **GetStatus 已返回结构化进度数据（276-290 行），VM 只取 StateText 拼文本** |
| `src/CureStation/App.xaml` | Fresh* 样式族（按钮/输入框/色板） | 主色板：#1E90FF / #1F4E79 / #B8D4EE / #5CB85C / #D9534F |

### 截图拆出的 6 个病灶（改前对照，改后逐条验收）

1. **大卡小字、下半全空**：4 行内容（约 80px 高）装进 ~250px 高的卡，视觉重心漂在中上部，剩余半截留白。
2. **层名与库位码割裂**：`A01` 左上 18px 深蓝，`第3-下层` 右上 11px 灰字，两个维度挤一行没有层次。
3. **状态没有重量**：三色灯只是 12px 的圆点 + 文本；30 张空闲卡全是 #FAFAFA 底 + 1px #DDD 边，无节奏、无强调。
4. **固化核心量（剩余时间）不可视化**：`SlotStatus.RemainMinutes` 数据现成，仅拼成 `计时中 剩47分` 一行小字， degrees 被浪费。
5. **托盘/光栅纯文本**：`L:ON R:OFF` 类文本读费劲，弱化处理即可，不必占主位。
6. **异常不聚焦**：红灯占用卡与空闲卡视觉权重几乎相同，异常点不能一眼锁定。

**一句话根因**：不是配色丑，而是**排版结构没有把"数据变成视觉层次"**——数据都有，只是被摊平成 4 行小字。

### 布局契约提醒（改 XAML 必看）

- 平铺 `Slots` 为**行优先**（先层后架），`MainVm_Slots_RowMajorOrder` 用例锁定了这个契约——卡片高矮不影响此项，但**别改集合顺序**。
- 双架渲染走 `RackGroups` 组内行优先，外层 `UniformGrid Rows=GroupCount`——D 方案只动"组内容器的底部追加物"，不动分组机制。
- 卡片**不设固定宽高**（拉伸均分，现有纪律），紧凑化只是给模板内部做 denser 结构 + `MinWidth` 类保护。

## 5. 实施指引（选定方案后按节开工）

### 5.1 `RackSlotViewModel` 新增展示属性（B/D 必做；A 不碰 VM）

```csharp
// Refresh(snapshot, hasTable, machineStatus) 里已有 SlotStatus?——把它结构化暴露：
// (属性放 RackSlotViewModel；命名跟现有 _camelCase 字段 + Raise() 通知习惯)
public int RemainMin      // 计时中剩余分钟（无则 0）
public int TotalMin       // 锁定的计划时长（无则 0；tooltip 显示"共 X 分"）
public double Progress    // 0.0~1.0，已固化比例 = 1 - Remain/Total（Total=0 时给 0）
public string StateKind   // Idle / Gate / Curing / Done / Alarm —— 五态，给样式 DataTrigger 用
```

映射注意（与现有 `CardState` 对齐）：

| SlotPhase | StateKind | 语义 | 进度条 |
| --- | --- | --- | --- |
| （machineStatus==null） | Idle | 空闲/未配置 | 隐藏 |
| WaitingGate | Gate | 待门控 | 隐藏 |
| Curing | Curing | 计时中 | 填充 Progress |
| Done | Done | 放行待取 | 满绿 |
| （灯红灯亮） | Alarm | 占用（传感器报备警示） | 隐藏 |

⚠ `CardState` 目前只有 Idle/Red/Yellow/Green 四态——**Gate（待门控）态当前并入"待判定"处理，改造时用 `StateKind` 区分红占用与待门控，别让两种语义共用一套底色**。

### 5.2 卡片模板结构蓝图（XAML 形态，B/D 通用）

```
DataTemplate SlotCard (Border 圆角 8~10、阴影极淡)
 ├ DockPanel 顶部: Code(大字) ─── 状态胶囊徽章(B) 或 层徽章(A)
 ├ 中部: ContentControl 按五态切模板
 │    Curing → 大号数字(RemainMin)+小字(共 Total 分·已固化Pct%)+进度条(6px 圆角)
 │    Done   → "✓ 已放行" + 小字(待取件)
 │    Gate   → "待门控" + 小字(光栅让空后计时)      ← 紫色系点缀
 │    Alarm  → "⚠ 占用" + 小字(红灯·请检查)         ← 红浸染底 + (B 只投这一卡) 脉冲
 │    Idle   → "空闲" 灰弱居中（整卡降不透明度 0.75）
 └ DockPanel 底部: 灯点(14px DropShadow 光晕)+托盘徽章(在架绿/无灰)
卡底 4px 状态色条 (Grid 底行 / Border 叠加)
```

写 XAML 的项目性纪律（违反会被打回）：

- 根节点 `xmlns:d/mc/vm` + `mc:Ignorable="d"` + `d:DataContext` `IsDesignTimeCreatable=False`；
- **数据触发的样式标签**：卡片样式切换底色继续用 DataTrigger（对齐现有 SlotCard 写法）；
- **所有展示绑定必须给 FallbackValue**（含徽章文本/进度百分比/灯文本），`Visibility` 绑定必给且多视图默认只留一个 Visible（`mc:Ignorable` 兜底，UI 叠层的教训见 CHANGELOG V0.0.11）；
- 数值绑定（Progress 双精度）配 `StringFormat`；**进度条用 `Rectangle` + `ScaleTransform` 或 Grid 列宽绑定**，别拖 ProgressBar 控件（模板重心太重，30 卡会慢）。

### 5.3 动画控制（B 的"异常脉冲"、悬停反馈）

- **只在 StateKind=Alarm 的卡上挂 Storyboard**（`RepeatBehavior="Forever"`，DoubleAnimation 挂 card Border 的 `Opacity` 或 `DropShadowEffect.BlurRadius`），Idle/Curing 卡不放动画——30 卡 constant 动画会拖析 UI；
- 更省的方案：异常卡不用动画，用"红浸染 + 红边框 + 卡底红条"三重静态强调，脉冲做**加分项**；
- 悬停反馈给整体单元格即可（hover 微放大/描边），不做 per-card DropShadow 常驻。

### 5.4 统计胶囊条（B 进阶，D 必含）

- 聚合在 `MainViewModel.RefreshSlots()`（500ms 已有节拍），遍历 `Slots` 一遍即可 30 次累加，成本忽略；
- 顶栏高度预算 34px：胶囊样式收编 `App.xaml`（新 `FreshStatBadge`），色板沿用语义色（灰=空闲 / 黄=计时 / 紫=待门控 / 绿=待取 / 红=占用报警），右侧加"剩余最短：X01·N 分"虚线胶囊（低值提示）；
- 铁律对照：统计只在 UI 线程刷新内存快照，零 IO，无线程问题。

### 5.5 D 方案下部两带（数据全现成）

**工单进度带**：

- 数据：`WorkOrderStore.Load()` → `WorkOrderBook.Right/Left`（RcNo/PresetQty/ProducedQty 字段详见 `WorkOrderStore` 注释，字段名对齐 MES 16 字段）；
- 刷新：跟 `RefreshSlots` 同拍检查（Load 是轻量 JSON 读盘，**500ms 全读一次可以接受但更稳的是对比 `LastWriteTime`，变了才 Load**——两方案都可以，选低依赖实现）；
- 展示：R/L 两卡，头 = 工单号，条 = ProducedQty/PresetQty，尾 = "已产出 n / 设定 m"；
- ⚠ 工单窗"清零/保存"后（`ShowWorkOrder` 返回 true）主窗需**主动重载一次**，别等下一个 500ms 才追上（或者统一每拍都读盘，孰简单孰好）。

**日志流**（数据链；承载形式见下方"独立悬浮窗"拍板小节）：

- 数据：`LocalLogService`（写文件 + 全量内存事件回调——调用方订阅即可，无需读盘）；
  ⚠ 事件在后台线程触发，**必须经 `UiInvoke` 封送**回 UI 线程再进 `ObservableCollection`；
- 展示（拍板后）：进**日志/控制台悬浮窗**（顶栏按钮弹出）——左流（`ListBox`，最新在上、条数封顶
  ~200 条防内存膨胀）+ 右"系统状态"小卡（IoBus 连接摘要/点表通道数/过账状态/策略名——全部主窗已有属性，聚合显示即可）；
- ⚠ 日志时间戳/格式收 `LocalLogService` 现有口径，不要二手拼字符串额外定格式；
- ⚠ 铁律对照：不新增任何网络/PLC IO；日志来自已有事件链，不碰 `_sync` 锁内回调红线（`CuringMesPosterHolder`/`PostingChanged` 订阅模式现成可抄）。

#### 日志/控制台的形态（2026-10-29 拍板：独立悬浮窗）

对"日志流固定占一屏底部"的改进——三形态对比（当时推荐 A；**最终用户拍板 C**）：

| 形态 | 交互 | WPF 实现 | 取舍 |
| --- | --- | --- | --- |

  （有新日志只推数据，不抢焦点）。

## 6. `E:\Project\galaxy` 素材库使用指引

### 6.1 它是什么（避免误用常见弯路）

- 来源：GitHub `uiverse-io/galaxy` 镜像 [Uiverse.io](https://uiverse.io/)——社区共享的 **CSS UI 元素集**，3000+ 个，License = MIT（附 attribution 礼节：建议给原创作者 + Uiverse.io 署名，但非强制）。
- 形态：按 `Buttons/ Cards/ Checkboxes/ Forms/ Inputs/ loaders/ Notifications/ Patterns/ Radio-buttons/ Toggle-switches/ Tooltips/` 目录分类，每文件 = 一个自包含 HTML demo（元素 + `<style>`，独立可双击打开预览）。
- **它是 CSS，不是 WPF**——不能直接引用，只能"挑视觉 → 手译成 XAML"。README 明确 PR 不接，纯素材库。

### 6.2 怎么挑

1. 直接用资源管理器/浏览器打开目标目录下任 `.html`（或整批拷进临时 HTML grid 浏览）优先看：
   `Cards`（726 个 —— 仓位卡/工单卡参考价值最高）、`Buttons`（顶栏按钮已是 FreshButton，除非要 3D 态）、`Tooltips`（悬浮详情）、`Toggle-switches`（配置窗开关）、`Notifications`（报警弹 Toast）；
2. **避开**：`loaders`（常驻动画耗性能）、`Patterns`（装饰性背景，工业界面降噪优先）、附带外部字体（Google Fonts 等）的组件——现场内网无外网字体；
3. 组件文件名 = `作者_随机Animals-序号.html`，看不出长相，**只能打开看**。请挑好后把文件名记进本文档决策记录再做翻译。

### 6.3 CSS → WPF 翻译对照表（本节是这份文档最值钱的部分）

| CSS 写法（galaxy 常见） | WPF/XAML 等价实现 | 性能/实践注意 |
| --- | --- | --- |
| `border-radius: 10px` | `Border.CornerRadius`（或 style Setter） | 无 |
| `border: 2px solid #xxx` | `BorderBrush/BorderThickness` + 状态切换用 `Style.Triggers` | 无 |
| `box-shadow: 0 6px 10px rgba(...)` | `Border.Effect` = `DropShadowEffect{BlurRadius,ShadowDepth=..,Opacity,Color,Direction=270}` | **鼠标 hover 才给 Effect**；30 张常驻Effects 会肉眼可见拖慢 |
| `background: linear-gradient(...)` | `Background` = `LinearGradientBrush`（StartPoint/EndPoint + GradientStops） | 控制在同一卡内一种方向，且 gradient 只放 subtle（浅蓝→白）不花哨 |
| `:hover { transform: translateY(-6px) }` | `Style.Triggers` 的 `Trigger Property=IsMouseOver` + `Setter TargetName Property=RenderTransform` + `RenderTransform` (TranslateTransform) | 同卡也给 `RenderTransform.Origin` 不需要；只动 Y |
| `transition: all .3s ease` | WPF 天成 transition 缺失：用 `Style.Triggers` + `EventTrigger/Storyboard`（`DoubleAnimation Duration=0:0:0.3` + `EasingFunction`） | 只在重点卡（异常/选中）用，禁止全表 per-card storyboard |
| `@keyframes pulse`（呼吸） | `ControlTemplate/Style.Triggers` 内 `Storyboard RepeatBehavior="Forever"` 动画 `Opacity` 或 `DropShadowEffect.BlurRadius` | **只给 Alarm 态卡挂**，其它卡不挂 |
| `svg path icon` | `Path` + `Data="M... Z"`（Geometry 剪裁）或 `TextBlock FontFamily="Segoe MDL2 Assets"` 字形 | SVG 源许可各异，**优先手绘简单几何 or MDL2 字形**，避免搬运不明的 SVG |
| `font-family: -apple-system, ...` | `FontFamily="Segoe UI"`（项目已默认），中文 `Microsoft YaHei` 兜底 | 不引_REMOTE 网络库 |
| `cursor: pointer` | `Setter Property="Cursor" Value="Hand"` | 无 |

### 6.4 工业界面的克制原则（倒过来列"不要抄什么"）

1. **不要动 Fresh 色板主线**：`#1E90FF`（主操作）/#1F4E79（深蓝字）/#B8D4EE（浅蓝边）/#5CB85C（绿）/ #D9534F（红）已贯穿全工程（登录窗/权限窗/配置窗），单窗页引新孤色会破视觉体系——galaxy 组件先按"把它的形状/骨骼搬过来，颜色换 Fresh 家族"处理；
2. **霓虹/玻璃拟态/3D 浮起按钮**只在登录窗这类低密度界面尝试；主窗 30 卡追求"一眼可读、异常扎眼"，不需要酒吧灯光；
3. **主窗绝不作 per-card 常驻动画/DropShadow**——只有异常卡和悬停态可以；
4. 灯/进度条圆角**克制到 4~6px**（过大圆角在窄卡里裁切内容，mockup 已踩过）。
