# 固化程控 操作员手册

> 适用版本：固化程控（CureStation）V0.0.20 及以后
> 适用对象：产线操作员（LEVEL.1 / LEVEL.2 账号即可完成本手册全部操作）
> 截图说明：文中截图均为**演示模式**数据（无真机时软件自带的模拟环境），
> 画面里的库位编码、剩余时间是演示值，以现场实际为准。

---

## 1. 这套软件是干什么的

固化程控软件安装在**固化炉旁边的工控机**上，负责两件事：

1. **自动计时**：托盘放进固化架后，软件按工艺策略自动开始倒计时，
   时间到了亮绿灯提醒你放行——不用看表、不用掐算；
2. **自动过账**（可选）：托盘进出炉时自动把信息报给 MES 系统，
   不用手工抄单。

软件管理 **2 台固化架、共 30 个仓位**（每台架 10 个站点 × 3 层），
屏幕上每个仓位一张卡，状态一目了然。

## 2. 开机与打开软件

1. 工控机开机，进入 Windows 桌面；
2. 双击桌面上的 **CureStation** 快捷方式（首次启动可能较慢，属正常）；
3. 软件自动最大化铺满屏幕，无需手动调窗口。

软件启动后自动连设备。屏幕左上角状态文字会显示：

- **演示模式（1 台配置）**：表示当前没接真机，软件在跑模拟数据——
  只有调试/培训时才出现这行字；
- 接真机时此处显示连接状态（连上/掉线自动重连）。

> 看板上如果出现**黄色三角或红字提示**，先对照第 8 节"常见问题"自查，
> 处理不了再叫工程师。

**界面总览**（演示数据）：

![主窗空闲态：30 张仓位卡 + 顶栏](images/cs-main-idle.png)

顶栏按钮从左到右：

| 按钮 | 干什么 | 什么人能用 |
| --- | --- | --- |
| 登录 | 输入账号进入操作身份 | 所有人 |

## 3. 登录

顶栏点 **登录**，弹出登录窗：

![登录窗](images/cs-login.png)

- **用户名**：点输入框右侧下拉箭头，会列出全部在册账号——选自己的；
- **密码**：输入自己的密码（出厂初始密码由管理员当面给，
  首次登录后立即改成自己的，见下文"修改密码"）；
- **记住密码**：勾上后下次自动填好（密码加密保存，电脑上不会出现明文）；
- 点 **登录**。

登录成功后顶栏你的名字会替代"未登录"，例如"操作员：zhangsan"。
在岗期间保持登录，交接班时点 **退出** 再让对方登录自己的账号——
**操作记录跟着账号走**，混用账号会查不到责任人。

### 修改密码

登录窗里点 **修改密码** 链接（或先登录后从顶栏进），弹出三框：

![修改密码面板](images/cs-login-pwd.png)

1. **原密码**：填现在的；
2. **新密码**：至少 6 位，且不能跟原密码相同；
3. **确认新密码**：再填一遍，两次必须一致；
4. 点 **保存修改**，提示成功即可。

> 忘记密码：找 LEVEL.4 管理员在权限管理窗里重置，自己解决不了。

## 4. 看板怎么读

每一张仓位卡，从上到下四层信息：

| 区块 | 内容举例 | 说明 |
| --- | --- | --- |
| 大标题 | A01 | 仓位编号（架 A~J 个位点编号） |
| 小标题 | 第1-上层 | 第 1 台架的上层 |
| 状态行 | 计时中 剩119分 / 空闲 | 当前动作与倒计时 |
| 底部 | 黄灯 托盘在 / L:ON R:ON | 灯色、托盘在位、两侧工位信号 |

**卡片颜色即灯色**：黄底=计时中，绿=可放行，灰=空闲。

![主窗运行中：多仓位黄灯计时](images/cs-main-flow.png)

流转各阶段的卡片样子（演示数据）：

| 阶段 | 卡片显示 | 你要做的事 |
| --- | --- | --- |
| 空仓 | 空闲 / 灰灯 托盘无 | 无 |
| 托盘进架 | 黄灯亮、开始倒计时 | 无（软件自动） |
| 计时中 | "计时中 剩xx分"、黄灯 | 等待，不要提前取件 |
| 时间到 | 绿灯亮 | 尽快放行（取出托盘） |
| 托盘离架 | 灯灭、回空闲 | 无 |

![另一时刻：另有六个仓位在计时](images/cs-main-flow2.png)

> 图里"剩119分"是因为截图时工艺时长 120 分钟刚开始 1 分钟——
> 是**演示值**，现场以你定的工艺策略为准。

## 5. 工单窗（操作员能做的全部在这里）

顶栏点 **工单** 打开工单信息窗。**LEVEL.1 操作员**进去后只能做三件事：

![工单窗操作员视角：计数清零按钮灰色不可用](images/cs-workorder-l1.png)

1. **员工工号（EMP_NO）**：录自己当天的工号；
2. **物料条码（BC_NO）**：录批次物料条码（注意是**批次级**，一炉一个）；
3. **保存工单**（右下角）。

其他字段（途程单号、预设数量、制程代码等）都**置灰只读**——那是
工程师及以上才改的，别尝试绕过，软件会在保存时把关。

**计数清零**按钮在操作员视角是灰色不可点（属 LEVEL.2 及以上）。

> LEVEL.2（班组长）可以做计数清零；
> LEVEL.3（工程师）可以编辑全部字段，见"客户技术工艺手册"。

**做批次核对**：过账开启时，保存工单会把物料信息自动报给 MES。
只见"已生产数量"涨数，不用自己记账。

## 6. 三条纪律（跑出来过教训的）

1. **时间没到不提前取件**。计时中把托盘拿走（光栅被触发），软件判定
   为"中途取件"：**该仓位计时作废**并记录日志——这板货按不合格处理，
   得从头再来。别赌运气，光栅每层都盯着。
2. **绿灯亮了尽快放行**。绿灯是"可以拿"的意思，别积压整层。
3. **一人一号**。操作都挂在你的账号下，混用账号查不到责任人。

## 8. 常见问题

**Q1：屏幕上仓位卡全灰、顶栏提示断线/重连，怎么回事？**
网络或设备临时掉线。软件每 5 秒自动重试，多数自己会好。
超过 1 分钟还没好：看设备电源、网线，找工程师。

**Q2：卡上有时突然又从"已成"变回"计时中"？**
说明灯被重计了。常见原因：重启了软件或电脑（突然断电也算）。
**这不是 bug**——宁可重计也不放行没固化够的货。如果工艺上非要
"断电接着算"，让工程师在策略里勾"断电续算"（那是客户技术工艺手册
里的事）。

**Q3：怎么确认过账开没开？**
看顶栏中间的绿字：显示"过账：已启用（R 工位）"即在线上报中；
显示"已停用"只说明不报 MES（程控照常，不受影响）。

**Q4：屏幕显示的一手数据跟实际货不一致？**
演示模式（屏幕左上角显示"演示模式"字样）时全部是模拟数据显示。
**交接班记录是否真机模式**，可直接问当日工程师，别对着演示数据
改你自己的工艺。
